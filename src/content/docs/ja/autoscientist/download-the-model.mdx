---
title: モデルをダウンロードする
description: 最良の AutoScientist チェックポイントをローカルのアーカイブにストリーミングします。
---

AutoScientist は、最良のイテレーションから[チェックポイントをダウンロード](/api/python/resources/autoscientist/methods/download)します。これは必ずしも最後のイテレーションとは限りません。このエンドポイントは、署名付き URL を返す代わりに、圧縮された tar アーカイブをストリーミングします。

`training_method="alignment"` の場合、ダウンロードは DPO ステージのものになります。

## チェックポイントをストリーミングする

まず[実行を取得](/api/python/resources/autoscientist/methods/get)し、完了していてダウンロード可能なチェックポイントが生成されていることを確認します:

```python
from adaption import Adaption

client = Adaption()

run_id = "autoscientist_run_abc123"
run = client.autoscientist.get(run_id)

if run.status == "failed":
    raise RuntimeError(f"failed: {run.error}")
if run.status != "succeeded":
    raise RuntimeError(f"Run is not complete: {run.status}")
if not run.download_available:
    raise RuntimeError("The checkpoint is not available for download")

with client.autoscientist.with_streaming_response.download(run.id) as response:
    response.stream_to_file("best-checkpoint.tgz")
```

ストリーミングレスポンスを使うことで、大きなモデルアーカイブをメモリに読み込まずに済みます。

## アーカイブを確認する

`tar` はアーカイブの圧縮形式を自動的に判別します:

```shell
mkdir -p best-checkpoint
tar xf best-checkpoint.tgz -C best-checkpoint
```

LoRA のチェックポイントには、通常次のものが含まれます:

```text
adapter_config.json
adapter_model.safetensors
tokenizer.json
trainer_state.json
...
```

Hugging Face に手動で公開するには、空のモデルリポジトリを作成し、展開したファイルをその Web インターフェースまたはツールでアップロードします。重みやトークナイザーに独自情報が含まれる場合は、アーカイブを非公開のままにしてください。

現在のレスポンスについては、[`download` API リファレンス](/api/python/resources/autoscientist/methods/download)を参照してください。
