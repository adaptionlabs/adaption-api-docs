## Adaption の Discord に参加する

製品に関する質問、API のサポート、トラブルシューティング、Adaption チームとコミュニティからのアドバイスについては、Discord に参加してください:

**[Adaption の Discord に参加する](https://discord.gg/sHhG8kwVav)**

技術的なサポートを依頼するときは、簡潔な問題の説明、関連する**データセット**と**実行**の ID、タイムスタンプ、エラーメッセージや HTTP ステータスコードを含めてください。

<Callout variant="note">
  API キー、認証情報、非公開のデータセットの内容、その他の機密情報を Discord に投稿しないでください。
</Callout>

## チームに個別に連絡する

アカウント固有の質問、請求、機密情報を含むサポート依頼については、Adaption チームにメールしてください:

**[support@adaptionlabs.ai](mailto:support@adaptionlabs.ai)**

より早く対応できるよう、アカウント名または組織名と、関連する技術的な背景を記載してください。

<Callout variant="tip">
  自分で解決したい場合は、[FAQ](/ja/resources/faq) とサイドバーの **API Reference** をご利用ください。
</Callout>
