---
title: Descargar el modelo
description: Transmite el mejor checkpoint de AutoScientist a un archivo local.
---

AutoScientist [descarga el checkpoint](/api/python/resources/autoscientist/methods/download) de la mejor iteración, que no es necesariamente la última. El endpoint transmite un archivo tar comprimido en lugar de devolver una URL prefirmada.

Para `training_method="alignment"`, la descarga corresponde a la etapa de DPO.

## Transmitir el checkpoint

[Recupera la ejecución](/api/python/resources/autoscientist/methods/get) primero y comprueba que haya terminado y producido un checkpoint descargable:

```python
from adaption import Adaption

client = Adaption()

run_id = "autoscientist_run_abc123"
run = client.autoscientist.get(run_id)

if run.status == "failed":
    raise RuntimeError(f"failed: {run.error}")
if run.status != "succeeded":
    raise RuntimeError(f"Run is not complete: {run.status}")
if not run.download_available:
    raise RuntimeError("The checkpoint is not available for download")

with client.autoscientist.with_streaming_response.download(run.id) as response:
    response.stream_to_file("best-checkpoint.tgz")
```

Usar la respuesta por streaming evita cargar en memoria un archivo de modelo de gran tamaño.

## Inspeccionar el archivo

`tar` detecta la compresión del archivo:

```shell
mkdir -p best-checkpoint
tar xf best-checkpoint.tgz -C best-checkpoint
```

Un checkpoint de LoRA suele contener:

```text
adapter_config.json
adapter_model.safetensors
tokenizer.json
trainer_state.json
...
```

Para publicarlo manualmente en Hugging Face, crea un repositorio de modelo vacío y sube los archivos extraídos a través de su interfaz web o de sus herramientas. Mantén el archivo en privado si los pesos o el tokenizador contienen información propietaria.

Consulta la [referencia de API de `download`](/api/python/resources/autoscientist/methods/download) para conocer la respuesta actual.
