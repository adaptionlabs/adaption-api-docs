import { Callout, Steps, Step } from "@stainless-api/docs/components";

Las claves de API autentican el **acceso programático** a Adaptive Data: las mismas capacidades de la plataforma que usas en la aplicación, invocadas desde tu código, tu automatización o tus notebooks. Trátalas como credenciales para integraciones en producción, no como tokens que se puedan compartir.

<Callout variant="note">
  Guarda las claves en un gestor de secretos o en variables de entorno. No las subas al control de versiones.
</Callout>

## Crear una clave en la aplicación

<Steps>
  <Step>[Inicia sesión](https://adaptionlabs.ai/app/auth) en Adaption.</Step>
  <Step>
    Abre [**Settings**](https://adaptionlabs.ai/app/settings) y la sección [**API keys**](https://adaptionlabs.ai/app/settings?tab=api_keys).
  </Step>
  <Step>
    Crea una clave, cópiala en ese momento y guárdala de forma segura. No podrás volver a verla.
  </Step>
</Steps>

## Usar la clave en Python

Pasa la clave explícitamente:

```python
from adaption import Adaption

client = Adaption(api_key="pt_live_...")
```

O define **`ADAPTION_API_KEY`** y construye el cliente sin argumentos:

```bash
export ADAPTION_API_KEY="pt_live_..."
```

```python
from adaption import Adaption

client = Adaption()  # reads ADAPTION_API_KEY
```

El mismo patrón se aplica a **`AsyncAdaption`** en código asíncrono.
