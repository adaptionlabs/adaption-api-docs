---
title: Inventar un conjunto de datos
description: Genera un conjunto de datos listo para el modelo desde cero, sin necesidad de un conjunto de datos de origen.
---

Invent genera un conjunto de datos listo para el modelo desde cero: no hace falta ningún conjunto de datos de origen. Describe tu conjunto de datos con un prompt, acótalo opcionalmente con dominios y subdominios, y la API crea un conjunto de datos para tu tarea.

Usa [`datasets.create`](/es/adaptive-data/create-a-dataset) cuando lo que quieras sea importar y adaptar un conjunto de datos existente.

### Qué puedes crear

- Los **conjuntos de datos de instrucciones** emparejan prompts con completions generadas para el ajuste fino supervisado.
- Los **pares de preferencia** ordenan dos completions entre sí para el entrenamiento basado en preferencias.

### Cómo funciona

1. **Describe tu conjunto de datos.** Usa `dataset_prompt` y, opcionalmente, `domains` y `subdomains` para guiar el proceso de invención del conjunto de datos.
2. **Estima (opcional).** Calcula el precio exacto de la solicitud con `estimate=True`. No se crea ni se cobra nada.
3. **Genera.** Llama a [`datasets.invent`](/api/python/resources/datasets/methods/invent) para crear el conjunto de datos e iniciar la generación. La llamada devuelve inmediatamente con el estado `running`.
4. **Sondea y descarga.** Sondea [`datasets.get`](/api/python/resources/datasets/methods/get) hasta que el estado sea `succeeded` y después [descarga las filas](#descargar-las-filas).

## Generar un conjunto de datos

Una sola llamada a `datasets.invent` crea el conjunto de datos y empieza a generar filas a partir de tu descripción y de las selecciones de dominio opcionales. Los ejemplos dan por hecho que has [instalado el SDK de Python y definido `ADAPTION_API_KEY`](/es/introduction/getting-started).

```python
from adaption import Adaption

client = Adaption()

dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    rows=1000,
    name="Clinical Q&A",
)

dataset_id = dataset.id
print(dataset_id, dataset.status)  # running
```

### Describir el conjunto de datos

Para inventar un conjunto de datos, proporciona **al menos uno** de los siguientes parámetros:

| Parámetro | Notas |
| --------- | ----- |
| `dataset_prompt` | Descripción de los datos que se van a generar. Si se omite, la descripción se genera a partir de tus selecciones de dominio. Máximo 10.000 caracteres. |
| `domains` | Códigos de dominio a partir de los que generar. Consulta [Elegir dominios y subdominios](#elegir-dominios-y-subdominios). |
| `subdomains` | Códigos de subdominio cualificados que acotan la generación. Consulta [Elegir dominios y subdominios](#elegir-dominios-y-subdominios). |

### Parámetros de la solicitud

| Parámetro | Obligatorio | Notas |
| --------- | ----------- | ----- |
| `rows` | Sí | Número de filas que se van a generar. Sujeto al límite de filas por lanzamiento de tu plan. |
| `name` | No | Nombre visible del conjunto de datos inventado. |
| `training_type` | No | `instruction_dataset` (predeterminado) o `preference_pairs`. Consulta [Elegir el formato de salida](#elegir-el-formato-de-salida). |
| `language_expansion` | No | Traduce o localiza una muestra de las filas generadas. Consulta [Expandir a idiomas y configuraciones regionales](#expandir-a-idiomas-y-configuraciones-regionales). |
| `estimate` | No | Devuelve una estimación de créditos sin crear ni lanzar un conjunto de datos. El valor predeterminado es `False`. |
| `idempotency_key` | No | Hace seguros los reintentos. Repetir una solicitud con la misma clave devuelve el conjunto de datos original en lugar de iniciar la generación de nuevo. Máximo 255 caracteres. |

### Calcular antes el precio de una solicitud

Define `estimate=True` para calcular el precio exacto de la solicitud. No se genera ni se cobra nada:

```python
estimate = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    subdomains=[
        "medical.symptoms_diagnosis",
        "medical.preventive_care",
    ],
    rows=1000,
    estimate=True,
)

print(f"Estimated credits: {estimate.estimated_credits}")
print(f"Available credits: {estimate.available_credits}")
```

## Elegir dominios y subdominios

Obtén los códigos actuales que acepta `datasets.invent` en lugar de codificarlos de forma fija:

```python
response = client.datasets.invent_domains()

for domain in response.domains:
    print(domain.code, domain.title)
    for subdomain in domain.subdomains:
        print("  ", subdomain.code, subdomain.title)
```

### Campos de dominio y subdominio

| Campo | Descripción |
| ----- | ----------- |
| `code` | El valor que se envía en `domains` o `subdomains`. Los códigos de dominio son valores como `medical`; los de subdominio son valores cualificados como `medical.symptoms_diagnosis`. |
| `title` | Nombre legible del dominio o subdominio. |
| `subdomains` | Subdominios disponibles dentro de un dominio. Una lista vacía significa que el dominio no tiene subdominios. |

### Acotar con subdominios

Pasa los códigos de subdominio exactamente como los devuelve `invent_domains`. `subdomains` es una lista plana de códigos cualificados:

Aquí, la parte médica se acota a los subdominios seleccionados. La parte jurídica se toma del dominio legal completo porque no se indicó ningún subdominio jurídico.

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical", "legal"],
    subdomains=[
        "medical.symptoms_diagnosis",
        "medical.preventive_care",
    ],
    rows=1000,
)
```


### Combinar varios dominios

Todos los códigos de `domains` contribuyen a la misma ejecución de generación. Para un dominio sin subdivisiones, pasa su código de dominio y omite los subdominios correspondientes.

## Configurar la generación

Configura el formato de salida, expande los idiomas y haz seguros los reintentos.

### Elegir el formato de salida

`training_type` tiene el valor predeterminado `instruction_dataset`. Defínelo como `preference_pairs` para obtener pares de completions elegidas y rechazadas:

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    training_type="preference_pairs",
)
```

Usa `instruction_dataset` para el ajuste fino supervisado estándar. Usa `preference_pairs` para el entrenamiento basado en preferencias, como DPO. Los mismos formatos se describen en [Configurar Adaptive Data](/es/adaptive-data/configure-adaptive-data#generar-pares-de-preferencia).

### Expandir a idiomas y configuraciones regionales

`language_expansion` usa la misma estructura que la [expansión de idiomas de Adaptive Data](/es/adaptive-data/expand-data):

- `translate` produce una nueva variante de fila para cada idioma de destino.
- `localize` produce una nueva variante de fila para cada par de país e idioma, con formulaciones propias de cada configuración regional en lugar de una traducción directa.

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    language_expansion={
        "type": "translate",
        "sample_rate": 0.25,
        "languages": ["es", "fr"],
    },
)
```

`sample_rate` es la fracción de filas inventadas que se expande para cada destino y debe estar entre `0.01` y `1`. Los créditos se facturan según el número de filas de salida expandidas.

Para la localización, pasa pares de país e idioma:

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    language_expansion={
        "type": "localize",
        "sample_rate": 0.25,
        "pairs": [{"country": "ES", "language": "ca"}],
    },
)
```

Los códigos de idioma o de país/idioma desconocidos devuelven una respuesta `400` con una muestra de los códigos admitidos.

### Hacer seguros los reintentos

Proporciona una clave de idempotencia cuando un fallo de red pueda hacer que tu aplicación reintente la solicitud:

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    idempotency_key="clinical-qa-2026-09-02",
)
```

Repetir la misma solicitud con esta clave devuelve el conjunto de datos original en lugar de iniciar otra ejecución de generación.

## Comprobar el estado y descargar

Sondea `datasets.get` con el ID del conjunto de datos inventado hasta que la generación informe de `succeeded` o `failed`.

### Sondear hasta que termine la generación

```python
import time

while True:
    record = client.datasets.get(dataset_id)
    if record.status == "succeeded":
        break
    if record.status == "failed":
        error = record.error_data
        message = (error and error.message) or "unknown error"
        raise RuntimeError(f"Dataset generation failed: {message}")
    time.sleep(5)

print(f"Generated {record.row_count} rows")
```

### Descargar las filas

Descarga el conjunto de datos completado como JSON Lines, JSON, CSV o Parquet:

```python
client.datasets.download(
    dataset_id,
    file_format="jsonl",
).write_to_file("clinical-qa.jsonl")
```

Consulta [`datasets.download`](/api/python/resources/datasets/methods/download) para ver todas las opciones de respuesta y de streaming.

### Ejemplo completo

```python
import time

from adaption import Adaption

client = Adaption()

domains = ["medical"]
subdomains = ["medical.symptoms_diagnosis"]

estimate = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=domains,
    subdomains=subdomains,
    rows=1000,
    estimate=True,
)
print(f"Estimated credits: {estimate.estimated_credits}")

dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    name="Clinical Q&A",
    domains=domains,
    subdomains=subdomains,
    rows=1000,
    training_type="instruction_dataset",
    idempotency_key="clinical-qa-2026-09-02",
)
dataset_id = dataset.id
print(dataset_id, dataset.status)  # running

assert dataset_id is not None

while True:
    record = client.datasets.get(dataset_id)
    if record.status == "succeeded":
        break
    if record.status == "failed":
        error = record.error_data
        message = (error and error.message) or "unknown error"
        raise RuntimeError(f"Dataset generation failed: {message}")
    time.sleep(5)

print(f"Generated {record.row_count} rows")

client.datasets.download(
    dataset_id,
    file_format="jsonl",
).write_to_file("clinical-qa.jsonl")
```

Para entrenar con el conjunto de datos generado, pasa su ID a [`autoscientist.create`](/es/autoscientist/running-autoscientist):

```python
run = client.autoscientist.create(dataset_id=dataset_id)
print(run.id, run.status)
```
