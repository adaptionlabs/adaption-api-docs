Adaptive Data está diseñado para entender y mejorar datos **en distintos idiomas**: el mismo análisis estructural y la misma optimización que impulsan la plataforma en inglés se extienden a cargas de trabajo multilingües a gran escala.

Las **ejecuciones de conjuntos de datos multilingües** te permitirán mantener prompts y completions en varios idiomas mientras aplicas una canalización coherente de adaptación y calidad, algo crítico cuando publicas modelos para usuarios de todo el mundo y necesitas una estructura comparable entre configuraciones regionales.

<Callout variant="note">
  Las **opciones del SDK** por ejecución para la configuración multilingüe
  **aún no están disponibles**. Esta página se actualizará con los parámetros y
  ejemplos cuando la función se publique.
</Callout>

Cuando se lance, esta guía mostrará cómo apuntar a columnas o metadatos específicos de un idioma y cómo se validan las salidas en cada configuración regional.
