Adaptive Data is built to understand and improve data **across languages**—the same structural analysis and optimization that powers the platform in English extends to multilingual workloads at scale.

**Multilingual dataset runs** will let you keep prompts and completions in multiple languages while applying a consistent adaptation and quality pipeline—critical when you ship models for global users and need comparable structure across locales.

<Callout variant="note">
  Per-run **SDK options** for multilingual configuration are **not available
  yet**. This page will be updated with parameters and examples when the feature
  ships.
</Callout>

When launched, this guide will show how to target language-specific columns or metadata and how outputs are validated per locale.
