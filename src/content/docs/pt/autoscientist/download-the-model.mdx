---
title: Baixar o modelo
description: Transmita o melhor checkpoint do AutoScientist para um arquivo local.
---

O AutoScientist [baixa o checkpoint](/api/python/resources/autoscientist/methods/download) da melhor iteração, que não é necessariamente a iteração final. O endpoint transmite um arquivo tar compactado em vez de retornar uma URL pré-assinada.

Para `training_method="alignment"`, o download pertence ao estágio de DPO.

## Transmitir o checkpoint

[Recupere a execução](/api/python/resources/autoscientist/methods/get) primeiro e verifique se ela foi concluída e produziu um checkpoint disponível para download:

```python
from adaption import Adaption

client = Adaption()

run_id = "autoscientist_run_abc123"
run = client.autoscientist.get(run_id)

if run.status == "failed":
    raise RuntimeError(f"failed: {run.error}")
if run.status != "succeeded":
    raise RuntimeError(f"Run is not complete: {run.status}")
if not run.download_available:
    raise RuntimeError("The checkpoint is not available for download")

with client.autoscientist.with_streaming_response.download(run.id) as response:
    response.stream_to_file("best-checkpoint.tgz")
```

Usar a resposta em streaming evita carregar um arquivo grande de modelo na memória.

## Inspecionar o arquivo

O `tar` detecta a compactação do arquivo:

```shell
mkdir -p best-checkpoint
tar xf best-checkpoint.tgz -C best-checkpoint
```

Um checkpoint LoRA normalmente contém:

```text
adapter_config.json
adapter_model.safetensors
tokenizer.json
trainer_state.json
...
```

Para publicar manualmente no Hugging Face, crie um repositório de modelo vazio e envie os arquivos extraídos pela interface web ou pelas ferramentas dele. Mantenha o arquivo privado se os pesos ou o tokenizador contiverem informações proprietárias.

Consulte a [referência da API de `download`](/api/python/resources/autoscientist/methods/download) para a resposta atual.
