<Badge intent="warning">Em breve</Badge>

O Adaptive Data foi criado para compreender e melhorar dados **em vários idiomas** — a mesma análise estrutural e otimização que impulsiona a plataforma em inglês se estende a cargas de trabalho multilíngues em escala.

As **execuções de conjuntos de dados multilíngues** permitirão manter prompts e completions em vários idiomas enquanto se aplica um pipeline consistente de adaptação e qualidade — algo essencial quando você entrega modelos para usuários globais e precisa de uma estrutura comparável entre localidades.

<Callout variant="note">
  As **opções do SDK** por execução para configuração multilíngue **ainda não
  estão disponíveis**. Esta página será atualizada com parâmetros e exemplos
  quando o recurso for lançado.
</Callout>

Quando for lançado, este guia mostrará como direcionar colunas ou metadados específicos de idioma e como as saídas são validadas por localidade.
