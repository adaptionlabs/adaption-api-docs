---
title: تنزيل النموذج
description: بُثّ أفضل نقطة تحقّق من AutoScientist إلى أرشيف محلّي.
---

ينزّل AutoScientist [نقطة التحقّق](/api/python/resources/autoscientist/methods/download) من أفضل تكرار، وهو ليس بالضرورة التكرار الأخير. وتبثّ نقطة النهاية أرشيف tar مضغوطًا بدلًا من إعادة عنوان موقَّع مسبقًا.

في حالة `training_method="alignment"`، يعود التنزيل إلى مرحلة DPO.

## بث نقطة التحقق

‏[اجلب التشغيلة](/api/python/resources/autoscientist/methods/get) أوّلًا وتحقّق من أنها اكتملت وأنتجت نقطة تحقّق قابلة للتنزيل:

```python
from adaption import Adaption

client = Adaption()

run_id = "autoscientist_run_abc123"
run = client.autoscientist.get(run_id)

if run.status == "failed":
    raise RuntimeError(f"failed: {run.error}")
if run.status != "succeeded":
    raise RuntimeError(f"Run is not complete: {run.status}")
if not run.download_available:
    raise RuntimeError("The checkpoint is not available for download")

with client.autoscientist.with_streaming_response.download(run.id) as response:
    response.stream_to_file("best-checkpoint.tgz")
```

يجنّبك استخدام استجابة البثّ تحميل أرشيف نموذج كبير في الذاكرة.

## فحص الأرشيف

تكتشف `tar` نوع ضغط الأرشيف:

```shell
mkdir -p best-checkpoint
tar xf best-checkpoint.tgz -C best-checkpoint
```

تحتوي نقطة تحقّق LoRA عادةً على:

```text
adapter_config.json
adapter_model.safetensors
tokenizer.json
trainer_state.json
...
```

وللنشر يدويًا على Hugging Face، أنشئ مستودع نماذج فارغًا وارفع الملفات المستخرَجة عبر واجهته على الويب أو عبر أدواته. واحتفظ بالأرشيف خاصًّا إذا كانت الأوزان أو المُرمِّز تحتوي على معلومات خاصّة بك.

راجع [مرجع واجهة برمجة التطبيقات لـ `download`](/api/python/resources/autoscientist/methods/download) للاطّلاع على الاستجابة الحالية.
