## Call a model or stack

Pass a model ID as `model` to call a hosted model directly. To call an inference stack, use `stack:<slug>`. The stack supplies its configured model, tools, datasets, and memory setting.

```python
from adaption import Adaption

client = Adaption()  # reads ADAPTION_API_KEY

response = client.responses.create(
    model="stack:your-stack-slug",
    input="Hello",
)

print(response.output_text)
```

Use a stack's slug when possible. `stack:<uuid>` remains supported for existing callers.

## List available models

Model availability can vary by API key. Pass `type="hosted"` to list the hosted models available to your key without including inference stacks or harnesses:

```python
from adaption import Adaption

client = Adaption()

for model in client.models.list(type="hosted").data:
    print(model.id)
```
