Runbooks take you through a complete workflow from start to finish. The notebook runbooks come from the [adaption-runbooks](https://github.com/adaptionlabs/adaption-runbooks) repo on GitHub. Each one has a page here and a notebook you can open in Google Colab or run locally.

## Get started

1. Get an API key from the [Adaption app](https://adaptionlabs.ai/app/auth). See [Create API keys](/introduction/create-api-keys).
2. Open a notebook in Colab and add `ADAPTION_API_KEY` to Colab secrets (🔑 in the sidebar).

To run the notebooks locally, clone the [repo](https://github.com/adaptionlabs/adaption-runbooks) and run:

```shell
export ADAPTION_API_KEY=...
uv run --with adaption --with jupyterlab jupyter lab
```

## App runbooks

These walk through the Adaption app, with no code.

- [Adaptive Data App Walkthrough](/runbooks/adaptive-data-app-walkthrough): import a dataset, map its columns, run adaptation, and review the results.
- [Processing Unstructured Documents](/runbooks/processing-unstructured-documents): turn PDFs, spreadsheets, and slide decks into a dataset.
- [AutoScientist App Walkthrough](/runbooks/autoscientist-app-walkthrough): pick a dataset, launch training, and read the result.
