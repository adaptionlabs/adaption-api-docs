The Adaption plugin for ChatGPT and Codex connects the [Adaption MCP server](/tools/mcp) and adds workflow skills for datasets, synthetic data generation, and AutoScientist. You sign in with your Adaption account in the browser; no API key is needed.

ChatGPT and Codex share one plugin directory, so the same Adaption plugin works in both.

## Install in ChatGPT

1. Open **Plugins** in the ChatGPT sidebar on the web, desktop, or mobile app.
2. Search for **Adaption** and open it.
3. Select **Install plugin**.
4. When prompted, select **Connect**. Sign in to Adaption, choose the organization, and select **Authorize**.

On Enterprise and Edu workspaces, an administrator must make the plugin available in the Admin console first.

To use the plugin, start a new chat and mention `@Adaption`, or select it from **+**. ChatGPT also uses it on its own when a request matches.

## Install in Codex

### Codex app

1. Open **Plugins** in the Codex app.
2. Search for **Adaption** and select **Add to Codex**.
3. Sign in to Adaption when prompted, then start a new thread.

### Codex CLI

1. Run `codex`, then `/plugins`.
2. Open **Adaption** and select **Install plugin**.
3. Sign in to Adaption when prompted. If Codex does not ask, run:

   ```bash
   codex mcp login adaption
   ```

4. Start a new session.

Plugins are not available in the Codex IDE extension. Install them from the Codex app or Codex CLI. Directory changes can take up to six hours to reach Codex.

## Verify the connection

In Codex CLI, check that `adaption` shows as logged in:

```bash
codex mcp list
```

Then ask:

> List my Adaption datasets.

ChatGPT or Codex should use `list_datasets` from the Adaption MCP server.

## Other ways to connect

### Install from the repository

To install the plugin from its repository instead of the directory:

```bash
codex plugin marketplace add adaptionlabs/adaption-codex-plugin
codex plugin add adaption@adaption
codex mcp login adaption
```

### Headless use with an API key

For CI or a machine without a browser, skip `codex mcp login` and authenticate with an [Adaption API key](/introduction/create-api-keys) instead. Set the key in the environment Codex runs in:

```bash
export ADAPTION_API_KEY="pt_live_..."
```

Add the server to `~/.codex/config.toml`:

```toml
[mcp_servers.adaption]
url = "https://api.prod.adaptionlabs.ai/api/v1/mcp"
bearer_token_env_var = "ADAPTION_API_KEY"
```

Restart Codex and run `codex mcp list` to confirm that `adaption` is connected.

## What the plugin adds

The plugin configures the hosted MCP connection and includes three skills:

- `adaption-dataset` — Guides dataset import, adaptation, augmentation, translation, localization, combination, and export workflows.
- `adaption-invent` — Guides synthetic dataset generation from natural-language requirements.
- `adaption-training` — Guides AutoScientist model selection, hyperparameter recommendations, training, and monitoring.

Skills give ChatGPT and Codex workflow guidance for chaining tools and handling asynchronous operations. See [MCP](/tools/mcp) for the shared server configuration and complete tool catalog.
