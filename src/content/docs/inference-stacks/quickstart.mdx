The Responses API generates model output from text or a list of messages. This guide takes you from a new API key to your first response in a few minutes.

This guide requires Adaption Python SDK version 0.16.0 or later.

## Create and export an API key

<Steps>
  <Step>[Sign in](https://adaptionlabs.ai/app/auth) to Adaption.</Step>
  <Step>
    Open [**Settings**](https://adaptionlabs.ai/app/settings), then open [**API
    keys**](https://adaptionlabs.ai/app/settings?tab=api_keys).
  </Step>
  <Step>
    Create a key and copy it. You will not be able to view the key again.
  </Step>
  <Step>
    Export the key as `ADAPTION_API_KEY`. The SDK reads this variable
    automatically:

    ```bash
    export ADAPTION_API_KEY="pt_live_..."
    ```

  </Step>
</Steps>

<Callout variant="note">
  Store API keys in environment variables or a secret manager. Do not commit
  them to source control.
</Callout>

## Install the SDK

```shell
pip install adaption
```

## Send a request

Call `responses.create` with a model and an input:

```python
from adaption import Adaption

client = Adaption()

response = client.responses.create(
    model="qwen3.5-397b",
    input="Write a one-sentence bedtime story about a unicorn.",
)

print(response.output_text)
```

`output_text` joins the text from every message in the response's `output` array. The full `output` array also includes any tool calls the model made.

To guide the model's behavior, add `instructions`:

```python
response = client.responses.create(
    model="qwen3.5-397b",
    instructions="You are a helpful assistant.",
    input="Hello!",
)
```

## Next steps

- Stream output as it is generated by passing `stream=True`.
- Continue a conversation with `store=True` and `previous_response_id`.
- Give the model tools, such as MCP servers and `file_search` over your adapted datasets.

See the [`responses.create` API reference](/api/python/resources/responses/methods/create) for all request parameters.
