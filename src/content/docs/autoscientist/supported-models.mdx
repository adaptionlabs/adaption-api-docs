Every model below can be passed as the `model` field when [creating an AutoScientist run](/autoscientist/running-autoscientist). The runtime model list is authoritative; use this page as a planning reference.

```python
response = client.autoscientist.list_models()
for model in response.models:
    print(model.id, model.api_model_size, model.methods, model.training_types)
```

See the [`autoscientist.list_models` API reference](/api/python/resources/autoscientist/methods/list_models) for the current response schema.

<Callout variant="note">
  You do not need to select a model. Omit `model` and AutoScientist selects one
  for the dataset. The resolved model ID is returned on the run.
</Callout>

### Batch size

Each model has one valid batch size. `batch_size` defaults to `"max"`, which resolves to that model-specific value. **Leaving it unchanged is the right choice for almost every run.** Supplying another integer causes the launch to fail after the job is accepted.

Models use gradient accumulation when a larger effective batch is useful. 

```python
# Recommended: let AutoScientist resolve the model and batch size.
run = client.autoscientist.create(dataset_id=dataset_id)

# Advanced: pin a model and its required batch size.
run = client.autoscientist.create(
    dataset_id=dataset_id,
    model="openai/gpt-oss-20b",
    hyperparams={"batch_size": 1},
)
```

### LoRA rank

`lora_r` accepts values from 1 through 64 for every model on this page. `lora_alpha` must be exactly one or two times `lora_r`; the API cross-checks the values when both are supplied in the same request.

## Row count

AutoScientist applies these hard minimums to the effective dataset size (processed rows plus configured augmentation):

- **SFT / instruction tuning:** at least **1,000 training rows**.
- **SFT → alignment tuning:** at least **12,000 training rows**. 

These training-method minimums are the same for LoRA and full fine-tuning. Model availability can be more restrictive: with fewer than **10,000 effective rows**, AutoScientist normally excludes full-size, non-VLM models in the Qwen, Gemma, and NVIDIA families. 

Text datasets can use augmentation to reach a minimum. Multimodal datasets cannot currently be augmented, so they must already contain enough processed rows. AutoScientist treats **20,000 rows** as a recommended quality target, not a hard launch requirement.

## Context length and your data

Training context is the maximum sequence length used during fine-tuning. It is shorter than the serving context and shorter for preference training than supervised fine-tuning. Rows longer than the training limit are truncated rather than rejected.
