Adaption 把通常只有前沿实验室才会使用的数据优化与模型训练技术带给日常团队。

- **[Adaptive Data](/zh/adaptive-data/overview)** 会分析并改进训练数据，让你能够导出可直接用于训练的数据集。
- **[AutoScientist](/zh/autoscientist/overview)** 会把模型训练与对齐背后的研究循环自动化，产出一个贴合你目标的模型。

这两款产品都可以通过 Adaption API 和 Python SDK 使用。

## 安装 SDK

```shell
pip install adaption
```

## 创建 API 密钥

<Steps>
  <Step>[登录](https://adaptionlabs.ai/app/auth) Adaption。</Step>
  <Step>
    打开 [**Settings**](https://adaptionlabs.ai/app/settings)，然后打开 [**API
    keys**](https://adaptionlabs.ai/app/settings?tab=api_keys)。
  </Step>
  <Step>
    创建一个密钥并复制它。之后将无法再次查看该密钥。
  </Step>
</Steps>

<Callout variant="note">
  请将 API 密钥保存在环境变量或密钥管理服务中，不要提交到版本控制系统。
</Callout>

## 在 Python 中使用密钥

在本地测试时，可以直接传入密钥：

```python
from adaption import Adaption

client = Adaption(api_key="pt_live_...")
```

在应用程序和 CI 中，请设置 `ADAPTION_API_KEY`：

```bash
export ADAPTION_API_KEY="pt_live_..."
```

SDK 会自动读取该环境变量：

```python
from adaption import Adaption

client = Adaption()
```
