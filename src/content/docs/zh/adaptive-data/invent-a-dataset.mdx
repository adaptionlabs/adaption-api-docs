---
title: 凭空生成数据集
description: 从零开始生成可直接用于训练的数据集，无需任何源数据集。
---

Invent 可以从零开始生成可直接用于训练的数据集——不需要源数据集。用一段提示词描述你想要的数据集，可选地用领域和子领域收窄范围，API 就会为你的任务创建一个数据集。

如果你想导入并适配已有的数据集，请改用 [`datasets.create`](/zh/adaptive-data/create-a-dataset)。

### 你可以构建什么

- **指令数据集**把提示词与生成的补全配对，用于有监督微调。
- **偏好对**对两个补全进行排序对比，用于基于偏好的训练。

### 工作原理

1. **描述你的数据集。** 用 `dataset_prompt` 以及可选的 `domains` 和 `subdomains` 来引导数据集生成过程。
2. **估算（可选）。** 用 `estimate=True` 为这次具体请求定价。不会创建任何内容，也不会扣费。
3. **生成。** 调用 [`datasets.invent`](/api/python/resources/datasets/methods/invent) 创建数据集并启动生成。该调用会立即返回，状态为 `running`。
4. **轮询并下载。** 轮询 [`datasets.get`](/api/python/resources/datasets/methods/get) 直到状态变为 `succeeded`，然后[下载数据行](#下载数据行)。

## 生成数据集

只需一次 `datasets.invent` 调用，即可创建数据集，并依据你的描述和可选的领域选择开始生成数据行。以下示例假定你已经[安装 Python SDK 并设置了 `ADAPTION_API_KEY`](/zh/introduction/getting-started)。

```python
from adaption import Adaption

client = Adaption()

dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    rows=1000,
    name="Clinical Q&A",
)

dataset_id = dataset.id
print(dataset_id, dataset.status)  # running
```

### 描述数据集

要凭空生成数据集，请**至少提供**以下参数之一：

| 参数             | 说明                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| `dataset_prompt` | 对要生成的数据的描述。如果省略，系统会根据你选择的领域自动生成一段描述。最多 10,000 个字符。             |
| `domains`        | 用于生成的领域代码。参见[选择领域与子领域](#选择领域与子领域)。                                          |
| `subdomains`     | 用于收窄生成范围的限定子领域代码。参见[选择领域与子领域](#选择领域与子领域)。                            |

### 请求参数

| 参数                 | 是否必填 | 说明                                                                                        |
| -------------------- | -------- | --------------------------------------------------------------------------------------------- |
| `rows`               | 是       | 要生成的行数。受你所用套餐的单次启动行数上限约束。                                          |
| `name`               | 否       | 生成数据集的显示名称。                                                                      |
| `training_type`      | 否       | `instruction_dataset`（默认）或 `preference_pairs`。参见[选择输出格式](#选择输出格式)。     |
| `language_expansion` | 否       | 对生成行的一个样本进行翻译或本地化。参见[跨语言与地区扩展](#跨语言与地区扩展)。             |
| `estimate`           | 否       | 返回额度估算，但不创建也不启动数据集。默认值为 `False`。                                    |
| `idempotency_key`    | 否       | 让重试变得安全。使用同一个键重复请求会返回原有数据集，而不会再次启动生成。最多 255 个字符。 |

### 先为请求定价

设置 `estimate=True` 可以为这次具体请求定价。不会生成任何内容，也不会扣费：

```python
estimate = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    subdomains=[
        "medical.symptoms_diagnosis",
        "medical.preventive_care",
    ],
    rows=1000,
    estimate=True,
)

print(f"Estimated credits: {estimate.estimated_credits}")
print(f"Available credits: {estimate.available_credits}")
```

## 选择领域与子领域

请动态获取 `datasets.invent` 当前接受的代码，而不要把它们硬编码：

```python
response = client.datasets.invent_domains()

for domain in response.domains:
    print(domain.code, domain.title)
    for subdomain in domain.subdomains:
        print("  ", subdomain.code, subdomain.title)
```

### 领域与子领域字段

| 字段         | 说明                                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `code`       | 在 `domains` 或 `subdomains` 中要传入的值。领域代码形如 `medical`；子领域代码是形如 `medical.symptoms_diagnosis` 的限定值。 |
| `title`      | 领域或子领域的可读名称。                                                                                                   |
| `subdomains` | 该领域下可用的子领域。空列表表示该领域没有子领域。                                                                         |

### 用子领域收窄范围

请严格按照 `invent_domains` 返回的形式传入子领域代码。`subdomains` 是一个由限定代码组成的扁平列表：

在下面的例子中，医疗部分被收窄到所选的子领域。法律部分则取自完整的法律领域，因为没有提供任何法律子领域。

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical", "legal"],
    subdomains=[
        "medical.symptoms_diagnosis",
        "medical.preventive_care",
    ],
    rows=1000,
)
```


### 组合多个领域

`domains` 中的每个代码都会参与同一次生成运行。对于没有细分的领域，只需传入它的领域代码，不必为它提供子领域。

## 配置生成

你可以配置输出格式、扩展语言，并让重试变得安全。

### 选择输出格式

`training_type` 默认为 `instruction_dataset`。若需要「已选」与「被拒」的补全对，请把它设为 `preference_pairs`：

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    training_type="preference_pairs",
)
```

标准的有监督微调请使用 `instruction_dataset`。DPO 等基于偏好的训练请使用 `preference_pairs`。[配置 Adaptive Data](/zh/adaptive-data/configure-adaptive-data#生成偏好对) 中也描述了同样的这些格式。

### 跨语言与地区扩展

`language_expansion` 使用与 [Adaptive Data 中的语言扩展](/zh/adaptive-data/expand-data)相同的结构：

- `translate` 为每种目标语言生成一个新的行变体。
- `localize` 为每个国家/地区与语言的配对生成一个新的行变体，除了直接翻译之外还会采用符合当地习惯的措辞。

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    language_expansion={
        "type": "translate",
        "sample_rate": 0.25,
        "languages": ["es", "fr"],
    },
)
```

`sample_rate` 表示为每个目标扩展的生成行比例，取值必须在 `0.01` 到 `1` 之间。额度按扩展后的输出行数计费。

进行本地化时，请传入国家/地区与语言的配对：

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    language_expansion={
        "type": "localize",
        "sample_rate": 0.25,
        "pairs": [{"country": "ES", "language": "ca"}],
    },
)
```

未知的语言代码或国家/地区与语言代码会返回 `400` 响应，并附带一部分受支持代码的示例。

### 让重试变得安全

如果网络故障可能导致你的应用重试请求，请提供一个幂等键：

```python
dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=["medical"],
    rows=1000,
    idempotency_key="clinical-qa-2026-09-02",
)
```

使用该键重复同一个请求会返回原有数据集，而不会启动另一次生成运行。

## 检查状态并下载

用生成数据集的 ID 轮询 `datasets.get`，直到生成结果报告为 `succeeded` 或 `failed`。

### 轮询直到生成结束

```python
import time

while True:
    record = client.datasets.get(dataset_id)
    if record.status == "succeeded":
        break
    if record.status == "failed":
        error = record.error_data
        message = (error and error.message) or "unknown error"
        raise RuntimeError(f"Dataset generation failed: {message}")
    time.sleep(5)

print(f"Generated {record.row_count} rows")
```

### 下载数据行

可以把已完成的数据集下载为 JSON Lines、JSON、CSV 或 Parquet 格式：

```python
client.datasets.download(
    dataset_id,
    file_format="jsonl",
).write_to_file("clinical-qa.jsonl")
```

所有响应与流式传输选项请参阅 [`datasets.download`](/api/python/resources/datasets/methods/download)。

### 完整示例

```python
import time

from adaption import Adaption

client = Adaption()

domains = ["medical"]
subdomains = ["medical.symptoms_diagnosis"]

estimate = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    domains=domains,
    subdomains=subdomains,
    rows=1000,
    estimate=True,
)
print(f"Estimated credits: {estimate.estimated_credits}")

dataset = client.datasets.invent(
    dataset_prompt=(
        "A dataset of medical question-answer pairs covering diagnoses, treatments, "
        "drug explanations, and healthcare roles. Each entry includes a prompt and a "
        "detailed, expert-generated response."
    ),
    name="Clinical Q&A",
    domains=domains,
    subdomains=subdomains,
    rows=1000,
    training_type="instruction_dataset",
    idempotency_key="clinical-qa-2026-09-02",
)
dataset_id = dataset.id
print(dataset_id, dataset.status)  # running

assert dataset_id is not None

while True:
    record = client.datasets.get(dataset_id)
    if record.status == "succeeded":
        break
    if record.status == "failed":
        error = record.error_data
        message = (error and error.message) or "unknown error"
        raise RuntimeError(f"Dataset generation failed: {message}")
    time.sleep(5)

print(f"Generated {record.row_count} rows")

client.datasets.download(
    dataset_id,
    file_format="jsonl",
).write_to_file("clinical-qa.jsonl")
```

若要用生成的数据集进行训练，请把它的 ID 传给 [`autoscientist.create`](/zh/autoscientist/running-autoscientist)：

```python
run = client.autoscientist.create(dataset_id=dataset_id)
print(run.id, run.status)
```
