## 加入 Adaption Discord

如需产品咨询、API 帮助、问题排查，或希望获得 Adaption 团队与社区的指导，欢迎加入我们的 Discord：

**[加入 Adaption Discord](https://discord.gg/sHhG8kwVav)**

寻求技术帮助时，请附上简明的问题描述、相关的**数据集（dataset）**与**运行（run）**ID、时间戳，以及任何错误信息或 HTTP 状态码。

<Callout variant="note">
  请勿在 Discord 中发布 API 密钥、凭据、私有数据集内容或其他敏感信息。
</Callout>

## 私下联系团队

如果问题与具体账户、计费相关，或者支持请求中包含敏感信息，请发送邮件给 Adaption 团队：

**[support@adaptionlabs.ai](mailto:support@adaptionlabs.ai)**

请附上你的账户或组织名称以及相关的技术背景，以便我们更快地处理请求。

<Callout variant="tip">
  如需自助查找答案，请使用侧边栏中的 [FAQ](/zh/resources/faq) 和 **API Reference**。
</Callout>

## 平台动态与一般咨询

若想**了解版本发布、新功能和公告**，或就非紧急的一般性话题联系我们，请使用 [adaptionlabs.ai](https://www.adaptionlabs.ai) 上的联系表单：

**[联系我们 —— Adaption](https://adaptionlabs.ai/contact-us)**

对于订阅更新，或发送与日常技术支持无关的消息，那个页面才是合适的入口。
