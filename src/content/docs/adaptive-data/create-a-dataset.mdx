import { Accordion, Callout } from "@stainless-api/docs/components";

Import data from a local file, Hugging Face, or Kaggle without writing a conversion script. Each method returns a `dataset_id` that you pass to [`datasets.adapt`](/api/python/resources/datasets/methods/adapt).

The examples assume you have [installed the Python SDK and set `ADAPTION_API_KEY`](/introduction/getting-started):

```python
from adaption import Adaption

client = Adaption()
```

<Accordion.Group>
  <Accordion>
    <Accordion.Summary>1. Upload a local file</Accordion.Summary>

    The SDK helper creates the dataset, uploads the file, and confirms the upload.

    Supported extensions: **`.csv`**, **`.json`**, **`.jsonl`**, and **`.parquet`**. Documents (**`.pdf`**, **`.docx`**, **`.pptx`**, **`.xlsx`**, **`.html`**, **`.txt`**, and **`.zip`**) upload the same way but need an extraction step first; see [Upload documents](#upload-documents).

    ```python
    dataset = client.datasets.upload_file("training_data.csv")
    dataset_id = dataset.dataset_id
    print(dataset_id)
    ```

  </Accordion>
  <Accordion>
    <Accordion.Summary>2. Import from Hugging Face</Accordion.Summary>

    Point at a Hugging Face dataset URL and the file(s) to import.

    ```python
    dataset = client.datasets.create(
        source={
            "url": "https://huggingface.co/datasets/tatsu-lab/alpaca",
            "files": [
                "data/train-00000-of-00001-a09b74b3ef9c3b56.parquet"
            ],
        },
    )
    dataset_id = dataset.dataset_id
    print(dataset_id)
    ```

  </Accordion>
  <Accordion>
    <Accordion.Summary>3. Import from Kaggle</Accordion.Summary>

    Use the Kaggle dataset page URL and the files to pull.

    ```python
    dataset = client.datasets.create(
        source={
            "url": "https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset",
            "files": ["spam.csv"],
        },
    )
    dataset_id = dataset.dataset_id
    print(dataset_id)
    ```

    **Kaggle credentials** must be registered in Adaption: open **[API keys settings](https://adaptionlabs.ai/app/settings?tab=api_keys)** (sign in if prompted) and add your Kaggle API credentials there before importing.

  </Accordion>
</Accordion.Group>

<Callout variant="note">
  Raw (passthrough) processing is currently supported only for local file
  uploads. Do not combine `processing_mode="raw"` with a Hugging Face or Kaggle
  URL. See [Run on non-adapted data](/autoscientist/run-on-non-adapted-data) for
  a local-file example.
</Callout>

## Upload documents

Documents are not rows yet. After the upload, Adaption counts their pages and waits for you to launch extraction, which turns the content into rows and costs credits.

Upload the file and wait for the page count. The dataset stops at `awaiting_input` with no `row_count`:

```python
dataset = client.datasets.upload_file("annual_report.pdf")
dataset_id = dataset.dataset_id

status = client.datasets.wait_for_completion(dataset_id)
print(status.status, status.row_count)
```

Check what extraction will cost before you launch it with [`get_preprocessing_credits`](/api/python/resources/datasets/methods/get_preprocessing_credits):

```python
quote = client.datasets.get_preprocessing_credits(dataset_id)
print(f"{quote.total_pages:.0f} pages cost {quote.extraction_cost} credits")
print(f"{quote.available_credits} credits available")
if quote.insufficient_credits:
    raise RuntimeError("Not enough credits to extract these documents")
```

Launch extraction with [`launch_preprocessing`](/api/python/resources/datasets/methods/launch_preprocessing), then wait again. When extraction finishes, the dataset returns to `awaiting_input`, this time with a `row_count`:

```python
launch = client.datasets.launch_preprocessing(
    dataset_id,
    preprocessing_mode="per_page",
)
print(f"Reserved {launch.credits_escrowed} credits")

status = client.datasets.wait_for_completion(dataset_id)
if status.status == "failed":
    error = status.error_data
    message = (error and error.message) or "unknown error"
    raise RuntimeError(f"Document extraction failed: {message}")
print(f"Extracted {status.row_count} rows")
```

`preprocessing_mode` decides how content becomes rows: `per_document` (the default) makes one row per document, `per_page` one row per page. To extract only part of the upload, pass either `pages_to_process` or `documents_to_process`, not both. `get_preprocessing_credits` accepts the same limits, so you can quote a subset before launching it.

<Callout variant="note">
  Launch extraction once per dataset. A second call fails with
  `adaption.ConflictError` (HTTP 409), and so does a launch before the page
  count finishes. If the team lacks the credits, the launch fails with HTTP 402
  and reserves nothing.
</Callout>

## Wait for the import

Imports run asynchronously. Poll the [dataset status](/api/python/resources/datasets/methods/get_status) until ingestion has populated the dataset before starting an adaptation run:

```python
import time

while True:
    status = client.datasets.get_status(dataset_id)
    if status.status == "failed":
        error = status.error_data
        message = (error and error.message) or "unknown error"
        raise RuntimeError(f"Dataset import failed: {message}")
    if status.row_count is not None:
        print(f"Imported {status.row_count} rows")
        break
    time.sleep(5)
```

Next, [map the imported columns](/adaptive-data/select-columns), then [configure the adaptation run](/adaptive-data/configure-adaptive-data). For endpoint details, see the [`create`](/api/python/resources/datasets/methods/create) and [`get_status`](/api/python/resources/datasets/methods/get_status) references. The `datasets.upload_file` helper handles the create, upload, and completion steps for local files.
